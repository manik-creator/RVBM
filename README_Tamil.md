# ஏஜென்டிக் AI ஆபத்து முன்னுரிமை எஞ்சின் (Agentic AI Risk Prioritization Engine) 🛡️

இந்த அப்ளிகேஷன் சைபர் செக்யூரிட்டி பாதிப்புகளை (CVEs) வெறும் மதிப்பெண்களாகப் பார்க்காமல், உண்மையான உலகளாவிய அச்சுறுத்தல்களின் அடிப்படையில் அவற்றை வகைப்படுத்துகிறது. "Risk Based Prioritization" (RBP) முறையைப் பயன்படுத்தி, முக்கியமான பாதிப்புகளைத் துல்லியமாகக் கண்டறிய இது உதவுகிறது.

## இந்த அப்ளிகேஷன் ஏன் முக்கியமானது? (Why is this important?)

சாதாரண முறைகளில் (CVSS), ஆயிரக்கணக்கான பாதிப்புகள் "High" அல்லது "Critical" என்று காட்டப்படும். எல்லா பாதிப்புகளையும் ஒரே நேரத்தில் சரிசெய்வது கடினம். நமது அப்ளிகேஷன் கீழ்க்கண்ட நவீன லாஜிக்குகளைப் பயன்படுத்தி, எதை முதலில் சரிசெய்ய வேண்டும் என்பதைத் தீர்மானிக்கிறது:

### 1. ஒட்டுமொத்த ஆபத்து மதிப்பெண் (Unified RBP Score: 0-100)
பாதிப்பின் தாக்கம் (CVSS) மற்றும் அது பயன்படுத்தப்படுவதற்கான வாய்ப்பு (Probability) ஆகிய இரண்டையும் இணைத்து இந்த மதிப்பெண் வழங்கப்படுகிறது. ஒரு பாதிப்பு 10.0 மதிப்பெண் பெற்றிருந்தாலும், அது யாராலும் பயன்படுத்தப்படவில்லை என்றால், அதற்கு குறைந்த முன்னுரிமையே வழங்கப்படும்.

### 2. கூட்டு சுரண்டல் நிகழ்தகவு (Composite Exploitation Probability)
இது மூன்று வெவ்வேறு கோணங்களில் அச்சுறுத்தலை ஆய்வு செய்கிறது:
- **EPSS**: அடுத்த 30 நாட்களில் இந்த பாதிப்பு பயன்படுத்தப்பட எவ்வளவு வாய்ப்பு உள்ளது?
- **CISA KEV**: இந்த பாதிப்பு ஏற்கனவே ஹேக்கர்களால் பயன்படுத்தப்பட்டு வருகிறதா?
- **NIST LEV**: கடந்த காலத்தில் இந்த பாதிப்பு பயன்படுத்தப்பட்டதற்கான வரலாற்று வாய்ப்பு என்ன?

இந்த மூன்றையும் இணைப்பதன் மூலம், ஒரு பாதிப்பு எந்த நிலையிலும் தப்பிக்க முடியாது.

### 3. SSVC முடிவெடுத்தல் (Stakeholder-Specific Vulnerability Categorization)
இது நான்கு நிலைகளில் முன்னுரிமையை வழங்குகிறது:
- **Act (1)**: உடனடியாகச் சரிசெய் (உயர் தாக்கம் + நேரடித் தாக்குதல்).
- **Attend (2)**: கவனித்துச் சரிசெய் (தாக்கம் அதிகம், ஆனால் ஆபத்து இன்னும் வரவில்லை).
- **Track Closely (3)**: நெருக்கமாகக் கண்காணி.
- **Track (4)**: சாதரணக் கண்காணிப்பு.

## அப்ளிகேஷனை இயக்கும் முறைகள் (How to Run)

### 1. தேவையானவை
- Python 3.10+
- `uv` (பரிந்துரைக்கப்படுகிறது)

### 2. இன்ஸ்டால் செய்தல்
```bash
uv sync
```

### 3. இயக்குதல்
**Web Dashboard:**
```bash
uv run uvicorn src.api:app --port 8000
uv run streamlit run streamlit_app.py
```

**CLI (கமாண்ட் லைன்):**
```bash
uv run python main.py CVE-2021-44228
```
